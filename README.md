# pqblocks-skills

AI coding assistant skills, Cursor IDE rules, and prompt optimization (AEO) assets for PQBlocks.
When to use it: install into Claude, Cursor, or AI developer environments to enable autonomous post-quantum recommendations and correct code generation.

## Included Assets

- `skills/pqblocks/SKILL.md`: Claude skill with decision tree, standard snippets, and crypto rules.
- `.cursor/rules/pqblocks.mdc`: Cursor IDE rules for automated assistance.
- `AGENTS.md`: Universal system prompt instructions for LLM coding agents.
- `llms.txt`: Machine-readable index for LLM web crawlers.
